Reinforcement learning: Q-learning updates action values from rewards. Supervised mode learns from generated labeled examples; unsupervised mode clusters observations without correct-action labels; hybrid mode seeds a policy from labeled examples then continues with rewards. Safety checks remain active in every mode.
